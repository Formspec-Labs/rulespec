# Criteria frozen before calls

## Passport

P1: IRLs definition preserves personalized standardized letters, date/signature,
and request for information/documentation/action to process an application.
P2: INs definition preserves notices informing passport bearers about passports.
P3: IRL alteration restriction includes Office approval plus the case-by-case,
management-approved extenuating-circumstances exception; examples retain scope.
P4: Each independent Posts cleared-language requirement retains the qualified
permission to modify it for local logistics/concerns, not just in another row.
P5: IN alteration restriction preserves its approval and exception boundaries.
P6: Adjudication before suspension covers all issues; IRLs are not guidance;
adjudication follows 8 FAM before selecting the appropriate IRL.
P7: INs need neither applicant response nor personalization with name/address.
P8: Consultation preserves Posts, tailoring circumstance, both indices or email.

Actors: agencies/centers on IRL alteration; Posts on use/modification/consultation;
literal you on pre-suspension adjudication; null on definitions and impersonal
adjudication. Passive IN actor agencies/centers is supported but less explicit;
report separately. Approvers must not replace actors. Do not expand Posts from
external knowledge. Combined IN response/personalization can leave actor null;
it has no single named actor for both components.

Terms: IRLs/information request letters and INs/information notices, supported
aliases and right defining rows. Alteration/language uses link IRLs; IN alteration
and response uses link INs; consultation links both. No invented definitions.

## Scoped controls

S1: Application-review RN is a request for missing application records, scoped
to application review; not the inspection-completion record.
S2: Equipment RN is a completion record, not a request; inspection scope survives.
S3: Applicant return requirement retains ten days and reviewer-extension exception.
S4: Reviewer permission retains five days and supervisor approval.
S5: Inspector issuance requires completed inspection.
S6: Operator archival permission requires manager approval.
S7: Literal you retains approval email; impersonal retention stays two years.
S8: ZX remains unexplained; do not invent an expansion or substantive definition.

Actor checks: Applicants, Reviewers, Inspectors, Operators and literal you on
their respective actions; null on definitions, passive retention and ZX. Never
substitute supervisors/managers as the acting party. Do not infer that you means
Operators merely because that role appears nearby.

Index checks: exactly two different RN senses with distinct IDs, correctly
supported definitions and aliases. Application definition, applicant return and
reviewer extension link only application RN. Equipment definition, inspector
issue and operator archival link only equipment RN. Generic email retention,
passive record retention and ZX do not require an RN link. An RN link inferred
for the email is context-sensitive; report it separately rather than automatically
fail a supported relation. All references resolve; definition IDs do not swap or
merge; every indexed definition has its right defining claim.

Per-statement qualification checks do not require acronym expansion at every
mention; sense links are assessed separately. Generic that deadline wording can
be context-dependent: record missing explicit antecedents separately while still
checking the stated threshold and condition. Read all output for other material
errors, not just the named checks. E must preserve all original B data exactly;
if B fails a check, E still fails it. No evidence or new link repairs source
meaning missing from a statement.
