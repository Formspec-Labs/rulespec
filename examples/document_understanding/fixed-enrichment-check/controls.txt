Constructed scoped-term controls — not an official document

Application review

For application review, a review notice (RN) means a written request for missing application records.

Applicants must return the RN within ten days unless a reviewer extends the deadline.

Reviewers may extend that deadline by five days only with a supervisor's approval.

Equipment inspection

Within equipment inspections, a review notice (RN) means a record that an inspection was completed; it is not a request for records.

Inspectors must issue an RN after completing an inspection.

Operators may archive that RN only after a manager's approval.

You must retain a copy of the approval email.

General record handling

Records must be retained for two years.

ZX is an external reference code whose meaning is not supplied here.
