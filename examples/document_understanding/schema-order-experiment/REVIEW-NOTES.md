# Source adjudication in progress

The reference expectations were frozen before requests. Decisions below concern
the accepted extraction output under each named invariant. A meaning can appear
in raw output yet fail this measure if the evidence parser or Core compiler
refuses its record. Component warnings alone do not fail a meaning case unless
they cause a refusal or undermine a named invariant. These are selected
development cases, not an overall accuracy score.

## Concept references and accepted relationships

All 343 emitted concept references name existing local concepts (225 with
definitions first, 118 with references first). All concept evidence quotations
occur exactly in the supplied document text. This verifies reference mechanics,
not identity or role correctness. The registries contain 55 and 30 concepts
respectively; scope and granularity differ across repeats.

A targeted raw-field review found clear role mismatches:

- Names/definitions-first/2 u15: object is name-change documentation, but its only
  object reference is c6, Form DS-11. The form is context, not the submitted item.
- The same run u14: the new-name-ID exemption refers to material discrepancy and
  Form DS-11 instead of the identity evidence named in its object field.
- Photos/definitions-first/2 u15: object is the returned passport application,
  but its reference is New photograph request, the purpose of returning it.
- The same run u4: object is the excluded parent's face, but its reference is
  Infant passport applicant. u27 has empty actor but an Applicant actor reference.

These are counterexamples, not an estimated error rate. Local IDs are useful for
reuse, but the model sometimes uses `object_refs` as broad topic associations.
Future schema work should distinguish topical concept associations from specific
actor/object identity and validate agreement between the reference and text.

All eighteen accepted qualification edges across all four variants were inspected
against their source and target meanings. They concern previous-name use,
medically necessary glasses or family spacing and target the appropriate
baselines. The invalid raw edges and lost qualifications remain disclosed.

Definitions-first emits seven raw relationship records: two structurally invalid,
one referencing a refused target, and four accepted. References-first emits
twenty-three: thirteen structurally invalid, two referencing refused records, and
eight accepted. Counts need those denominators; the latter attempts more links.
