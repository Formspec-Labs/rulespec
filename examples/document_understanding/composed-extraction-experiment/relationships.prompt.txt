Return one entry for each supplied B000-style statement identifier, using an
empty qualifications list where no supported qualification can be attached.
Copy that identifier as unit. Qualification evidence selects supplied source
passage IDs or inclusive contiguous ranges. Keep section citations in references.
Code resolves evidence exactly and binds the qualification to that selected
statement. This target selection does not prove the relationship's meaning.

Use scope for the case in which the baseline applies, prerequisite for something
that must hold before the baseline action is allowed or required, trigger for the
event or situation that activates it, and exception for a supported carve-out.
Do not use relation none. Include ALL inherited case limits in each qualification
statement and its evidence. Refer to the actual action and case in natural prose,
not a vague it. A long supporting passage does not compensate for missing meaning.

Before attaching a qualification, determine exactly which action or proposition
it changes. A separate conditional duty remains its own baseline with its own
condition; it is not automatically a prerequisite for a nearby exemption. A
conditional permission does not cancel another duty. A supporting explanation
is not an applicability limit. Particularly and generally do not themselves
create prerequisites. A descriptive caution does not automatically restrict a
person's desire or permission. Preserve must, should, may, might and negation.
If a source relaxes one aspect of a standard, do not waive other aspects.

For remote-only exceptions, do not invent unavailable contents as a local
qualification. Retain them in the existing statement's references. If the proper
target is absent or the relation type does not express the source accurately,
leave that qualification unasserted. A deadline saying do X before Y is not a
prerequisite of X itself. The readable timing meaning already remains in the
first-pass statement; do not force an incorrect link just to represent it again.
