# Standalone qualification experiment

Decision: Does a more concrete instruction in the existing statement description
help a split rule preserve its qualifications without contaminating independent
rules or weakening successful grouped output?

Observed: the current CUE #Summary already asks for complete self-contained meaning,
and #ScopeText and the extraction prompt repeat that requirement. The prompt also
explicitly splits different actions and modal forces. Passport C0005/C0006 retain
a duty and qualifying permission across two records, leaving the duty with no
explicit qualification. Notice C0014 loses an inherited lead-in. The waste case
successfully groups nested exceptions and alternatives. A new synonym alone may
add no value; this is one bounded test before stopping such prompt iterations.

Hypothesis: replacing the general #Summary description with a concrete standalone
consumer check will retain qualifications in the original duty/permission statement
and scope, while preserving separate independent meanings. If only the quote grows,
only a neighboring record retains the qualification, unrelated conditions spread,
or baseline already passes with no other gain, the proposed benefit is weakened.

Alternative explanations: the same evidence may support grouped-source discovery
but not independent rule use; a description change may not overcome segmentation
preferences; improvements may reflect single-run variation. This experiment cannot
choose among hidden reasoning explanations or establish repeatability.

Arms: B is the current native-CUE-generated provider schema. T replaces only the
first #Summary documentation paragraph with the standalone-use instruction saved
in the isolated CUE source. Keep the existing example-inheritance paragraph. Use
the native CUE generator and existing models; no extra fields or schema vocabulary.
Assert the sent provider schemas differ only in statement.description, and actual
prompts/configuration otherwise match per case. Production files remain unchanged.

Cases: full saved 8 FAM 801.2-1 passport source; full saved 29 CFR 825.303 notice
source; full saved Ohio 3745-52-15 waste rule; one constructed counterexample document
with three separately labeled scenarios (independent actions by different actors,
independent permission by the same actor, and parallel differently scoped branches).
All are now development or constructed controls, not independent evaluation gold.

Targets fixed before calls:
- Passport: a cleared-language duty must include authorized adaptation for local
  needs in its statement to satisfy the stronger standalone-use preference. Track
  scope and logic separately. Combined duty+permission or separate complete rules
  are acceptable. Do not invent an unconditional right to change IRLs or transfer
  agency/center approval requirements to posts. Original wording does not explicitly
  mean unaltered, so label failure as qualification visibility rather than proved
  legal falsehood. Keep all earlier passport checks from the transfer PLAN.
- Notice: any designated-number permission must retain unforeseeable-leave context
  and the unusual-circumstances/emergency limits. Score statement, scope and logic
  separately; the full source context remains supplied. Preserve first/subsequent
  notice alternatives and stabilization AND phone access AND ability to use it.
- Waste: preserve the closed-container duty and complete handling/necessary-venting
  exception tree; both label components; excess-triggered three-day compliance OR
  removal with all three destinations and interim duties. No forced splitting
  requirement: complete grouped meanings are acceptable.
- Controls: visitors filing on arrival versus staff optionally working remotely;
  staff's unconditional signing duty versus independent option to use a blue pen;
  winter ski-pass duty versus summer bicycle permission. No transfer of actors,
  timing or optional permission into a waiver/precondition of an independent duty.
  All six meanings must remain independently recoverable; combining only if the
  constituent scopes and forces remain explicit is not automatically failure.

Held constant: gemini-3.8-flash, temperature 0, low thinking, no numeric thinking
budget or application output cap, 24,000-character windows, unchanged examples,
normal parsing/Core conversion and graph checks. One extraction call per case/arm:
EIGHT calls maximum. Every case fits one window. Alternate pair order B/T, T/B,
B/T, T/B. Existing five-minute timeout; no retries, audit calls, repair or tuning.
One repeat per cell prioritizes counterexamples over repeatability; temperature
zero does not establish determinism. Keep all attempts and failures.

Assessment: compare raw response statements and all compiled meaning fields against
source, with arm labels hidden for initial primary-agent review and arm order
randomized within case; candidate order is retained for source traceability. Then inspect full evidence and processing. Labels are
revisable. Keep semantic visibility, source support, processing completeness,
instruction adherence, cost and generalization separate. Replay has zero provider
calls and does not establish fresh behavioral repeatability.

Decision: bounded support only if T meets both target improvements relative to B,
preserves all waste checks and avoids counterexample contamination. If a baseline
already meets a target, report no reproduced benefit there. Any material regression
prevents the broad gate passing. Equal successful meaning can still differ in cost.
Stop after eight calls; do not patch wording again based on these results. Production
adoption is a separate decision. Save the observations and decide whether to pursue
a broader evaluation, consumption change or a different hypothesis.
