# Sparse meaning and compact audit inputs

Decision: implement the user's requested statement-first extraction with nullable,
omittable optional fields, and reduce repeated audit input without losing meaning.
Use canonical CUE and existing capture, evidence, evaluation and replay code.

Extraction hypothesis: a complete statement plus optional enrichment instructions
will avoid mechanically filling scope/choice/logic fields. Two fresh low-thinking
runs (passport and waste) check actual schema acceptance, optional-field adherence,
qualification/exception/alternative retention and raw-to-Core conversion. Earlier
saved outputs are historical references, not contemporaneous controls. No causal
accuracy or savings claim follows from that comparison.

Audit hypothesis: retaining meaning fields and replacing exact source quotations
with existing passage references, while omitting empty fields, reduces input
without losing the four planted errors or damaging nearby correct claims.
Use three frozen comparisons: passport B and waste B from audit-mutation-sensitivity,
and notice A from audit-field-distinction. The notice failure is a known miss;
measure its verdict separately, never score a continued miss as success. Named
nearby correct claims are negative controls: passport C0012, waste C0007 and the
unchanged notice claims. Labels are revisable development judgments.

For each comparison, send both the current baseline request and the compact request
in fixed randomized order. Hold drafts, source inventories, output schema, model,
temperature 0, medium thinking and provider output cap fixed. Record exact requests,
raw responses, token usage, complete accounting, target verdicts and rationales.
No re-extraction or fresh inventory for those six comparisons.

Acceptance: native schema drift and parser/replay tests pass; statements remain
nonempty/required, optional omissions/null normalize deterministically without
inventing meaning, populated invalid fields remain refused. Audit input tokens
should fall at least 20% in each paired case; all four planted errors must remain
visible with specific rationales, and no new false errors on named neighboring
controls. Notice completeness is an open secondary measure. Any semantic regression
blocks claiming the compact audit as a validated improvement and needs inspection.

Stop at eight provider calls: two extraction checks and six comparisons. No retries,
repairs, automatic approval or follow-on calls. Inspect raw output and preserve
failures. Replay uses saved captures and zero provider calls. These selected cases
do not establish general accuracy or that less context necessarily improves reasoning.
