# Original teacher scope test: reminder failed

Completed four calls on the byte-identical original teacher paragraph and context:
two control, two treatment. Both arms use the frozen passage-ID prototype; only
the treatment's meaning-field description changes, using the same reminder as the
previous synthetic experiment.

All four retain the inaccurate-record condition in the general employer burden,
then drop it from the separate teacher requirement. Teacher-condition success:
control 0/2, treatment 0/2. Teacher details and references otherwise survive;
no adjacent conditions transfer. All four STOP, resolve evidence, and replay
identically. Total reported tokens: 12,585.

Decision: no observed benefit; do not adopt the reminder as a fix. This reproduces
the original failure that the easier synthetic cases did not. The output pattern
suggests loss of the relationship between a conditional rule and its illustrative
example, rather than empty scope_refs alone. The internal cause remains uncertain.

Next proposed test: explicitly instruct inheritance for illustrative examples,
except when the source changes scope. Compare the original paragraph with a
scope-changing example to catch over-inheritance. Not executed. Production
unchanged; research local and uncommitted.
