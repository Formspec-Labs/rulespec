# Blind process B: initial observations

Recorded before reading experiment README, prior review conclusions, assessment labels, or model audit judgments. Read both raw source texts, the extraction requests and all 13 alcohol / 15 rail-crossings raw extraction statements. A required lightweight memory search exposed generic historical guidance about distinguishing exact evidence from semantic correctness, but no conclusions about these captures. These observations are my own source-to-extraction comparison.

- Alcohol extraction looks unusually faithful as readable prose. It preserves four-hour/24-hour/30-day/10-day timing, separate driver and motor carrier roles, both possession exceptions, and the alternative reporting deadline after an affirmation. It does not manufacture an enforcement actor for the passive out-of-service duty.
- Alcohol authority statement correctly treats affirm/reverse as an assigned power; the Regional Director of Motor Carriers remains separately named rather than silently reconciled with Division Administrator or State Director.
- Alcohol possession exceptions are embedded in the base prohibition. They are searchable as text, but no independent exception nodes exist yet. A relationship pass could add graph usefulness; it need not rewrite this good baseline.
- Alcohol reporting has two conditional routes in one complete sentence. This is accurate but requires interpretation for workflow generation; a simple must node is not yet an executable deadline.
- Rail extraction preserves all 18 placard list items, including repeated Division 5.1 and the Division 1.2/1.3 alternative. Keeping the source duplicate is good provenance; it should not imply two independent obligations.
- Rail stopping prohibition, permission to cross safely in a suitable gear, and prohibition on shifting are distinct. The first prohibition bundles stop/look/listen/no train approaching. Stop exemptions must not accidentally waive the other safety actions through a coarse relationship to that bundle.
- Rail exemptions preserve useful details: business district, police officer OR flagman, functioning green light AND local law, abandoned sign, and Exempt sign. The last sign erection duty is separate. No missing exemption is apparent from this manual read.
- Rail base statements refer to local paragraphs rather than expanding all classes and stop exemptions. Other extracted statements retain the content; this is workable for discovery if nearby source is presented, but weaker than the prompt's strong promise of a completely self-contained default reading.
- Actor extraction is selective: rail exemptions/sign erection have no actor, appropriately avoiding guessing. Term arrays are empty; these provisions refer to definitions elsewhere rather than defining terms locally.
- Exact evidence ranges for later rail exemptions span the prior exemption items because the common lead-in is included in a contiguous range. This is grounded but noisy and unsuitable as an assumption that all quoted text qualifies each node.
- Initial opinion: useful source-faithful search enrichment, with obvious source display and feedback. Graph relationships and automatic workflow decisions deserve a separate inspection. More passes must demonstrate added benefit over these already good baseline sentences.
