# Railroad crossings: manual assessment before revealing the mapping

Both versions preserve all five no-stop cases and their source conditions. They
retain the independent prohibition on changing gears and the requirement for
appropriate State/local authority involvement in Exempt signs. The green-signal
case retains functioning signal, green indication and permission under local law;
the industrial-switching case retains its business-district limit. The 15–50 foot
range, listening/looking/no-approaching-train prerequisites, safe gear permission,
and six vehicle categories remain represented. The long placard list remains an
OR, including the source's repeated Division 5.1 entry.

Version 2 explicitly connects all five exemptions to the grouped stop/listen/look
prohibition C0000. This is a defensible target because each modifier says only
that a stop need not be made, not that all crossing precautions disappear. No
modifier targets the no-gear-change prohibition or the sign-consent requirement.
Consumers still need modifier meaning; a graph edge alone is not blanket cancellation
of all baseline components. Version 1 retains the five exemptions without targets.

No default statement becomes more faithful: meanings already exist in version 1.
Version 2 makes five existing exemption relationships explicit without duplicating
their statement records. The baseline still refers to paragraph (b), and vehicle
scope remains largely textual/cross-referenced rather than a fully structured model.

Substantial evidence repetition is visible in both versions. Each successive
exemption's main quotation starts at the shared '(b) A stop need not be made at'
header and includes all previous siblings. Every exemption also carries the same
full paragraph (a) as context. This preserves inherited evidence but makes packets
large and puts irrelevant sibling text next to a narrow claim. It is a source-range
selection issue visible before refinement, not a newly invented semantic statement.

The same paragraph is also reused for the first three rules' main/scope evidence
and as context for vehicle-category statements. Preserve provenance, but treat
this as an opportunity to improve evidence addressing/packet construction, not a
reason to discard inherited context. No changes are made during this experiment.

Version labels were randomized; explicit edges make timing inferable. Same-agent,
partially blinded engineering review, not independent reference labeling. The
raw stage outputs, review history and consumer export are checked separately.
