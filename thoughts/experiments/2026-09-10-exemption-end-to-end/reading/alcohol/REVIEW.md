# Alcohol: manual assessment before opening the version mapping

Both versions retain all three frozen scenarios in ordinary statements: shipment
and bus-passenger exclusions are limited to possession; requesting review changes
the State-report deadline while preserving reporting after affirmation. Neither
changes the separate 24-hour employer report or excuses driver alcohol use.
Four-hour restrictions, immediate 24-hour removal, issuance-based commencement,
24-hour employer notice, 30-day State notice and 10-day written review petition
remain distinct. The two later review authorities/permissions are retained.

Version 2 adds two separate exceptions, each correctly targeting C0002 possession,
with explicit wording limiting its effect to possession. Version 1 already retains
both exceptions inside C0002. This is an explicit graph-link gain, not a repair to
the default statement or a newly discovered source meaning. Version 2 leaves the
review-dependent deadline grouped within C0009, which remains semantically faithful.

Both versions retain component-evidence warnings for inherited/repeated actor and
modal words, despite readable correct actor and force fields. Several internal and
external references remain unresolved. These warnings are not evidence of missing
main-statement meaning, but they limit claims of fully grounded structured output.

The two companion exceptions repeat portions of their target statement and carry
concept labels plus actor/action/object/scope wording. This makes the graph usable
but introduces representational repetition. No duplicate independent duty was
created. No existing standalone exemption appears in these drafts, so this case
does not directly exercise the new exemption-edit capability.

Version labels were randomized. Added records make before/after inferable; this is
partial blinding by the same agent that selected and judged the sources. Raw
capture, challenge, review history and consumer export still require layer checks.
