# Fresh-document qualification of explicit section grouping

Decision: does the existing task-grouping intervention merit a full-document
qualification run? The user's "Continue" resumes this narrower investigation
after choosing to retain production. It does not revive the archived twenty-call,
three-arm proposal. No production changes or commits are part of this test.

Hypothesis: explicitly separate tasks in a shared request can amortize repeated
instructions/schema while preserving individually usable meanings. Counter-
prediction: additional neighboring source causes duty merging, misplaced scope,
or loss of report/list referents. A capacity explanation is also possible:
separate calls have two output allowances. These calls test the scheduling and
task-directive bundle, not its components or hidden model reasoning.

Arms: A, two current separate-section requests; B, their complete union with the
exact task directive from the prior pilot. Keep current passage presentation,
CUE schema, prompt examples and deterministic parser unchanged. Do not improve
the directive after seeing results. Preserve all source words, notes and tables.

Cases: three previously untested section pairs from the official 2025 annual CFR:
21 CFR 211.188/211.192 (drug manufacturing records/review), 14 CFR 91.123/91.125
(air-traffic instructions/light signals), and 45 CFR 164.310/164.312 (physical/
technical information safeguards). A search of prior experiment Markdown and
retained request JSON found no use of those exact section identifiers. This is
fresh evaluation relative to the local studies, not a claim about model training
or a representative legal benchmark. Add the original CSBG 9913/9914 pair as a
known report-reference regression case. No other sections are being tested.

Source preparation: retain downloaded XML, URLs and hashes. The installed XML
entry point rejects the annual CFR wrapper. For this model-input experiment,
render the complete selected SECTION bodies as pinned plain text: normalize XML
formatting whitespace, preserve paragraph order and inline text, and retain table
headers/rows/cells using line breaks and tabs. Use the existing prepare_document
API for explicit section boundaries. Compare rendered non-whitespace text with
the source body before calls. This is a research text snapshot, not qualification
of annual XML ingestion or native publisher-coordinate replay. The original CSBG
document is reused unchanged. Groups must fit 6,000 focus characters.

Predeclared checks are in EXPECTATIONS.md, written from the raw sources before
any fresh model calls. Judge the complete default statement independently from
supporting fields, then inspect actor/modality, evidence and relationships. Equal
record counts or schema validity do not establish equivalent meaning.

Held constant: installed production runtime at the recorded git commit,
gemini-3.8-flash, low thinking, provider-managed sampling, 16,384 output tokens
per request, no extra audit/refinement, no retries. One observation per arm/case;
alternate A-first and B-first across pairs. Maximum twelve generation calls and
twenty minutes of capture, with the existing five-minute per-call timeout. Retain
failed calls and partial outputs. A time limit stops new calls; an already sent
call can finish within its timeout. Report provider usage, not guessed billing.

Decision rule: advance only with at least 15% aggregate total-token savings and
no observed new material omission, changed obligation, broken alternative/scope,
or newly ambiguous necessary referent relative to the paired control. Show each
case and separate fresh cases from the CSBG repeat. Shared baseline defects stay
visible and do not require fixing all existing behavior. Missing/truncated or
refused content is not silently dropped to improve metrics. Mixed results mean
hold production unchanged and stop this round, not another prompt patch.

Review: randomize and anonymize arm order for source-based quality review. Record
uncertain judgments and source-preparation limits. Replay every response through
the native decoder and validate against its actual requested schema. Passing
this small study would support another decision, not establish general accuracy
or automatically authorize adoption.
