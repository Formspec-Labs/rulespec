# Qualification target enumeration

Decision: whether enumerating candidate local target rules improves useful applied
qualification links without relaxing unrelated duties. This is an experiment;
there is no production adoption or new permanent schema.

Observation: both previous catalog arms omitted the refrigerant listed-substitutes
exemption's link to the local service rule. Earlier seatbelt relationships omitted
a section-wide exclusion's links. Recording an exemption is not finding its scope.
Hypothesis H1: general correction framing encourages stopping after a first obvious
target. Explicitly checking every existing qualification against local non-qualification
claims will increase final correct edges. H2: the model instead treats a separate
edge as redundant when the target already states its scope; enumeration will not
change the refrigerant omission. H3: broad enumeration increases false links or copy
errors. One sample cannot establish stable rates or choose hidden-reasoning causes.

A: current general relationship prompt. B: identical prompt plus a compact matrix
of existing condition/exception/exemption aliases and every non-qualification alias,
with instructions to consider each pair and permit no supported link. Keep ordinary
proposal fields/schema, source data, challenge prompt/schema, settings and review
application unchanged. B does not receive expected answers. A and B both use the
current passage-reference challenge. It is an instruction-plus-enumeration bundle.

Cases: original refrigerant draft/packet from evidence-catalog; original full 14 CFR
91.107 provider extraction/packet from relationship-audit. Both are historical
selected development inputs, not fresh documents. Fresh paired model calls are
contemporaneous. Choosing the saved seatbelt case avoids inventing uncertain target
labels for an arbitrarily chosen new source and supplies multiple real targets and
local exceptions that must not relax nearby pilot duties. Generalization remains open.

Frozen expectations: refrigerant C0001 -> C0000 and C0004; C0002 -> C0000 only
(C0003/C0004 forbidden). Seatbelt C0015 -> C0000,C0001,C0002 with other local rules scored separately; preserve unless otherwise stated.
Nested child-restraint provisions include notwithstanding language, so blanket
links to every local rule are uncertain rather than mandatory positives.
C0003 dock exception -> C0002 only; C0016 paragraph (a)(3) exclusion -> C0002
(primary), with its local paragraph-(a)(3) components acceptable but never C0000 or
C0001. Permission-as-qualification links need separate source-supported additions;
do not rewrite the original permissions. No invented external section contents.
Refrigerant C0001 -> C0004 is an explicit graph completeness judgment; C0004 already
says non-exempt. It is not evidence the original duty statement was inaccurate.

Held constant: exact shared saved books/packets, model gemini-3.8-flash, temperature
0, provider-default thinking, output limit32768, one sample/arm/case, randomized cell
order seeded20260917. Maximum8 calls,20 minutes; no retries, full audits or tuning.
Both candidates follow decoder, preview, passage-reference challenge and ReviewStore.

Decision rule: investigate further only if B repairs at least one required missed
edge beyond A, retains all A's primary correct edges, applies no false target or
unsupported relaxation, preserves all original meaning/evidence fields, and uses
<=1.5x A total reported tokens. Otherwise no change or tradeoff. Report proposed,
decoded, challenged and applied separately. Existing actor/source warnings, refusals
and missing usage remain visible. Raw manual review is revisable agent judgment.
Replay verifies decoding and application/reload separately from semantic correctness.

packet without audits for both arms. Preserve the historical book separately;
