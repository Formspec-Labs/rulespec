# Existing evidence helps discovery; no new budget selector adopted

**Keep the production paths unchanged.** Adding existing verified evidence after
source ranking recovered the selected support for one more new question under
the fixed budget. Both proposed allocations needed two gains to pass, so neither
met the [declared gate](PLAN.md). The existing uncapped evidence path recovered
two; that is a separate result, not a retrospective pass for the capped variant.

| Same questions, uncapped | 6/8 | 8/8 | 8/8 |

| New-question source characters delivered, total | 6,865 | 8,854 | 8,940 |

All arms ranked identical source text and returned the same three hit identities.
The corpus contains 420 source rows: the four earlier retrieval documents and
one additional retained title-20 chapter. Its first baseline model observation
was reprocessed by the delivered retention fix. The whole chapter, including
editorial text and unprocessed sections, stayed searchable. These are existing
development sources and agent-authored questions, not untouched documents or a
real-user evaluation. The four control questions retain their original labels;
their scores cannot be compared with the prior run as though the corpus were
unchanged.

## What the comparison showed

- **Useful existing signal:** the de minimis question's source result ends at
  “only if they occur when.” B/C recover both actual compliance paths. They also
  recover duties for an empty hazardous-material tank, but the cap prevents all
  crossing exceptions from fitting. Uncapped evidence contains that support.
- **Source allocation matters, but is not enough:** B can replace a direct result
  with an unrelated expansion or editorial note. C preserves all source text A
  admitted, but adds no selected-support gain over B on these cases.
- **More evidence does not fix every miss:** the nonconsecutive-employment
  control still lacks its seven-year qualification even without the cap.
- **Avoid another deduplicator:** the diagnostic packet representation repeats
  quotations under different roles. The production discovery export already
  shares evidence by identity and records those roles together. Its actual JSON
  duplication rate was not measured here.

The [manual review](RAW-REVIEW.md) examines all twelve cases, including irrelevant
hits, source text displaced by B and important material outside the original
labels. “All selected support” is narrower than a complete legal answer. The
1,500-character budget is an experimental variable, not a proposed extraction or
model context limit. One expected support selection exceeds it before ranking.
Budgeting complete fragments also cannot guarantee a complete exception list.

All mechanical controls pass: no-statement source fallback, duplicate statement
evidence, fabricated context refusal, separate source identities and whole-fragment

unknown pinpoint unresolved, and retains competing source/edition-label candidates.
Those navigation controls are separate from the lexical experiment.

source-coordinate accounting. The [additional edition control](edition-control.json)

No application code, dependency, schema, default or installed wheel changed.
No provider calls were made. The new experiment files and task-list update are
research work.
