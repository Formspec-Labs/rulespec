# Integrated context for fixed statements — pre-run decision

Decision: does the delivered source/reference/evidence foundation help a focused interpretation task enough to connect that task to the existing review workflow?

Hypothesis: the broad extraction task previously failed to use available reference context, whereas a fixed statement and explicit question can use it to expose a missing condition or resolve a referenced definition. Alternative: the model still omits conditions or falsely inherits neighboring rules despite receiving them. This bundled integration cannot attribute gains to an individual reader, context size, or feedback field.

Arms: A supplies the fixed statement (or selected actual source passage), current `with_context(2400)` and its verified evidence. B supplies that same focus plus complete short sections (up to 12,000 characters), directly related claim evidence, one-hop unique located reference targets and their containing sections (up to 6,000 characters), relevant recorded feedback and reader/source limitations. B adds at most 20,000 unique source characters across sources; omit whole additions and record the decision when over budget. No recursive lookup, inferred title, or automatic edition match. The larger allowance than the earlier selector is a declared part of this bundle, not a tuned result.

Both arms use the same current retained draft and same focused questions, source-aware response schema, instructions, model settings and actual capture helpers. Context text is deduplicated by pinned source identity/positions, retaining roles separately. External positions never enter the primary document's resolver. Existing CUE `SourceRef` describes each local passage selection; the experiment adds the supplying source alias to choose which existing catalog/resolver applies. No new Core representation.

Cases (six, selected development cases; not an independent benchmark): original refrigerant default prohibition; original dated seatbelt labeling; the retained State-agency definition from the completed USLM experiment; actual Federal Register good-cause citation with the delivered Title 5 section fixture; the original constructed visitor/staff noninheritance control; the same actual citation with two explicitly constructed competing publisher versions and experimental feedback. The external fixture is an original section and metadata in a declared constructed wrapper. Feedback controls are labeled experimental observations, not real human corrections. Freeze questions and source-reviewed expectations before provider calls.

Measures: per-question correct grounded additional meaning, partial meaning, honest abstention, unsupported additions, actor/modality/scope errors, irrelevant inheritance, uncertainty preservation, and source-reference validity. Count natural cases separately from constructed controls. Inspect raw answers, not only enums. Retained extraction/primary-statement accuracy is not directly measured by a question-answer proxy. Stage usage is not whole-document cost.

Gate: investigate/deliver the optional focused review connection only if B gives a complete additional source-grounded answer on at least two of the four natural cases, introduces no critical actor/modality/scope/exception error relative to A, respects missing/ambiguous editions and misleading-parent controls, and every asserted source reference resolves in its supplying source. Report partial improvements separately; unknown is appropriate when source selection fails. B mean total reported tokens must be no more than 2× A; missing usage is unresolved. Passing a selected diagnostic gate allows only a bounded optional capability, not a new default extraction pass or a general accuracy claim. No change to the previous failed experiment's verdict.

Bound: at most 12 calls (six cases × two arms), one observation per arm, alternating AB/BA order, Gemini 3.8 Flash, temperature 0, low thinking without a token thinking budget, max output 32,768, candidate count 1. No retries or prompt tuning after first call. Raw captures and all failures count. If a preflight fails, preserve the failed command/observation, fix the mechanical issue, and refreeze before any live call.

Preflight: preserve original inputs; exact source slices across inserted whitespace; distinct sources with identical offsets; duplicate/repeated targets; ambiguous editions; no unseen-text ranges; unchanged statement/review data; retained refused readings and feedback pins; no-op evidence and budget checks. Reuse current schema/capture/review/source readers. Freshness is verified from current files and installed bytes, not a version string alone.

After results: manually compare raw output with pinned source/labels, replay captures, and record adopt/investigate/defer. If supported, integrate the small source-aware context/review adapter with optional explicit calls and existing review observations; validate normal command/reload/export and installed behavior. Meaning edits and per-target subset application retain existing preview/revision checks and are separate from automatic observations. Do not upgrade sibling dependencies or drift to metadata work.
