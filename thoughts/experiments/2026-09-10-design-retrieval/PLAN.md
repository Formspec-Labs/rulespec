# Retrieval pilot — frozen before ranking

Decision: Does a combined source-plus-meaning/context index justify broader discovery evaluation, compared with source-only and statement-only retrieval?

Hypothesis: Meanings supply readable terms and inherited context missing from short source items; keeping source paragraphs protects material omitted by extraction. Combined indexing should improve complete source support at rank 3. A weaker prediction is identical recall with increased context cost. Long repeated statements may instead dilute ranking or crowd results.

Arms: A source passages; B extracted statement summaries; C source passages augmented with every automatically linked statement plus verified scope/context, using the existing `discovery.records(..., 'packets')` association. No manually selected gold context enters C. All arms use unchanged `evaluation/discovery_trial.search` lexical BM25, fixed defaults and top 3. A secondary 6,000 unique-evidence-character budget checks whether context inflation explains gains. Source IDs and evidence coordinates remain intact.

Cases: Four historical provider-extracted books: 29 CFR 825.110 leave eligibility, 49 CFR 392.5 alcohol, 49 CFR 392.10 railroad crossings, and 40 CFR 82.154(a)-(b) refrigerants. These are development material, NOT untouched holdout. Existing FAM holdout labels are not opened or used. Freeze corpus copies and 16 agent-authored, source-reviewed queries before ranking. Include literal/paraphrase, inherited qualifications/exceptions, an apparently unextracted nonconsecutive-employment provision, and overlapping evidence/duplicate-hit controls. Labels are provisional exact support fragments, not human gold or complete legal answers. Supplemental controls remove all statements and duplicate identical statement revisions; they test mechanics, not real omissions/rates.

Held constant: Corpus snapshot, query strings, labels, same lexical search function/tokenizer and ranking limits. Zero API calls, zero new dependencies, one deterministic run + replay. Stop after the fixed cases; no tuning. The current harness is reused instead of introducing a second search implementation. It is not a maintained external BM25 package. The lexical test cannot establish benefits of embeddings or semantic search.

Decision rule: Investigate C further only if complete support@3 improves over A and B with no per-query loss relative to A, and the improvement survives the fixed evidence-character budget. Any A regression fails the broad gate. Equal support with more context cost is no retrieval improvement. Keep production unchanged in all cases: this small, synthetic-query pilot cannot establish real-user benefit. Report first relevant rank, relevant support and complete context separately, evidence character/duplication burden, raw false hits and omissions. Source preparation/granularity and different record counts are part of each representation bundle; credit no one component as causal.
