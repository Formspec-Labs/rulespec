# Can existing evidence recover incomplete standalone meaning?

Decision: whether existing source-packet retrieval is sufficient to address lost
qualifications, before spending on a new extraction representation. This is a
bounded diagnostic; it does not authorize production adoption.

Observation: the saved Posts statement omits its local-modification permission.
Other saved statements lose remote exclusions or inherited prerequisites.

Hypotheses:
- H1: the required meaning survives in main evidence; returning that evidence
  should recover it without another extraction call.
- H2: the required meaning survives only in linked scope/context passages;
  existing packets should recover cases that main evidence cannot.
- H3: necessary dependencies are absent from both selections; packet retrieval
  will still omit them and extraction/link selection needs work.
These explanations may apply to different cases. Seeing words in context does
not establish their governing relationship or repair the default statement.

Arms: A = unchanged default statement; B = A plus verified main evidence;
C = A plus source passages linked to the claim by existing discovery.records
packets and their verified evidence. Preserve distinct source spans in document
order; deduplicate exact spans. Do not infer qualification links, traverse an
entire document, or add a custom parent parser.

Cases (all saved development data; none is a fresh generalization test):
1. Passport paragraph cell-01: Posts cleared-language duty and local permission.
2. Seatbelts paragraph cell-00: initial pilot takeoff duty, Administrator
   authorization and remote part 121/125/135 exclusions.
3. Recording sentence cell-05: encouragement to follow recommended treatment,
   with medical-treatment-beyond-first-aid prerequisite. This is an actual prior
   failure in a non-adopted experimental arm, reported separately.
4. First-aid paragraph cell-04: supplies duty; inherited clinic-proximity scope
   is uncertain. Do not force a reading merely because the sentences co-occur.
5. Constructed paragraph cell-03: visitor public-tour and librarian archive
   exemptions must remain distinct actor/activity pairs.
6. Constructed paragraph cell-03: sign AND date annual report before submitting;
   extra context must not change AND to OR or confuse the two AR meanings.

Held constant: same saved claims, sources and evidence per case, current
production discovery helpers, one deterministic evaluation per arm. Zero model
calls, zero provider spend, six cases, no retries or post-result arm tuning.
Record file/runtime hashes and full displayed spans. Run the script again only
to confirm deterministic artifact replay, using a separate output directory.

Assess separately: exact source locations; required meaning present in returned
material; meaning explicit in default statement; unresolved attachment/sense;
unrelated material; rendered character count (not provider tokens); user benefit.
Manually read source and all six results. This is an unblinded revisable human-
style agent assessment, not an independent model judge or legal determination.

Decision rule: packet retrieval is sufficient on this set only if all three
known-loss targets recover their named prerequisites/exclusions and the three
controls preserve distinctions/uncertainty without invented relationships.
If any fails, report not solved even if some context becomes available. A
narrower benefit must be reported separately. Character overhead is descriptive;
this experiment cannot establish retrieval ranking or downstream answer accuracy.
If main evidence already recovers a case, do not credit packet expansion for it.

Stop after the six-case manual review and deterministic replay. Preserve original
captures and write the result alongside this plan; production remains unchanged.
