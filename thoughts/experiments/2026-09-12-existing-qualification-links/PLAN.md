# Can existing references connect an already captured qualification?

Decision: Identify the smallest missing connection between captured requirements
and their governing qualifications, without adding another general audit pass.

Hypothesis: Existing publisher references can locate the attendance/excusal
targets of the separately captured IEP writing requirement. A bounded join of
located source targets to current claim evidence may expose those relationships
without rediscovering their text. A located citation is not itself a semantic
qualification verdict. Missing addresses, ambiguous overlapping claims, or a
non-governing reference must remain visible rather than become automatic links.

First comparison: Trace the existing reference scan, native source index, claim
evidence, and context export on the unchanged saved iep-1 and lea-1 books.
Distinguish source availability, located citation targets, mapped current claims,
and established qualification roles. No new model calls in this phase. Preserve
raw scan results and original books, with source/runtime hashes.

Cases: IEP writing rule R006 should point to attendance R004 and excusal R005.
IEP team definition R003 and transition invitation R007 are unrelated-target
controls. LEA's external citations must retain unavailable/ambiguous targets;
the policy-purpose lead-in must not be treated as a governing condition solely
because it is nearby. The cases and manual expectations are development data.

Measures: Does existing code locate the correct supplied paragraph bodies? Does
the current context view expose the referenced or referring extracted meanings?
Does joining current main evidence to a target produce a unique interpretation
or several candidates? Are original kind/modality/statement/review identities
preserved? Record limitations and incorrect candidate matches, not only positives.

Bound and decision: Two saved books, no provider calls, no production mutation.
Reuse existing readers and source/evidence resolution; do not write a new citation
parser. If association is mechanically available, create a reviewable experimental
view and identify the next semantic test. If it is unavailable, document the exact
reader/representation gap before changing code or conducting more model tests.
Any later test of comprehension must have its own pinned inputs and distinguish
manual correct links from automatic discovery. New production behavior needs
evidence beyond successful source lookup.
